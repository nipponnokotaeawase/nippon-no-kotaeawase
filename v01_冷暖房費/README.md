# v01 同じ家を47か所に置いたら、冷暖房費はいくら変わるか

まったく同じ家を、日本の47か所に置いたと考えて、年間の冷暖房費を計算しました。
このフォルダのファイルだけで、動画に出てくる数字はすべて再現できます。

---

| ファイル | 中身 |
|---|---|
| `01_入力_月別平均気温_実測12か月_47地点.csv` | 気象庁の実測。2025年8月〜2026年7月、47都道府県の代表地点 |
| `02_入力_月別平均気温_平年値30年_47地点.csv` | 気象庁の平年値（1991〜2020年の30年平均）。比較用 |

| `04_結果_年間冷暖房費_47都道府県.csv` | 計算結果。動画のランキングはこれ |

## 何を計算したか

### そろえた条件（47都道府県すべてで同じ）

| 項目 | 値 |
|---|---|
| 延べ床面積 | 120m²（2階建て想定） |
| 断熱性能 | 省エネ基準 等級5（UA=0.60 W/m²K） |
| 熱損失係数 | 234.6 W/K（貫流184.2＋換気50.4） |
| 設定温度 | 冬20℃ / 夏27℃ |
| 度日の基準温度 | 暖房18℃ / 冷房24℃ |
| 家族構成・在宅時間 | 全国同一 |

**地域で断熱を変えていないのが、この企画の核です。**
家を固定して、気温と電気代だけを動かしたとき、何がどれだけ効くのかを見るためです。

### 計算式

```
月ごとに
  必要な熱量(kWh) = 熱損失係数 × (基準温度 − 月平均気温) × 24時間 × その月の日数 ÷ 1000
  使う電力(kWh)   = 必要な熱量 ÷ (そのときのCOP × 霜取り係数)
これを12か月ぶん足して、電気単価(円/kWh)をかける
```

### COP（エアコンの効率）

外気温で効率が変わることを織り込んでいます。**この番組の主張の中心です。**

| 外気温 | 暖房COP |
|---|---|
| 15℃ | 5.5 |
| 7℃ | 4.6（定格点） |
| 2℃ | 3.8 |
| −7℃ | 2.8 |
| −15℃ | 2.2（以下は2.0で下限） |

- **霜取り**: 月平均が −5〜+3℃ の月は、暖房COPを0.85倍。
  着霜は0℃前後の湿った空気で最も起きるため、−10℃以下の乾いた寒さより
  0℃前後のほうが効率を落とします
- **冷房**: COP = 5.0 − 0.10 ×(月平均気温 − 24)、下限3.2

### 電気単価

各社の従量電灯 **第2段階**（月120〜300kWh。家庭の標準的な使用量帯）に、
再エネ賦課金 4.18円/kWh（2026年度）を足した値を使っています。
燃料費調整額は毎月・会社ごとに動くため、含めていません。

## 主な結果（基準ケース）

| | |
|---|---|
| 最も高い | 北海道（札幌） 240,317円/年 |
| 最も安い | 鹿児島県（鹿児島） 44,708円/年 |
| 倍率 | 5.38倍（差額 195,609円/年） |
| 東京 | 82,516円/年（47都道府県中 24位） |
| 効率一定と仮定した場合の札幌 | 178,440円 → **実際より26%安く見える** |

最後の行が、この回のいちばん言いたいことです。
よく見かける試算は、エアコンの効率が外気温で落ちることを織り込んでいないため、
**寒い土地の暖房費を2〜3割小さく見せています。**

## 感度分析 — 729通り（`05` の中身）

前提の置き方で数字は動きます。そこで主要な仮定6つを各3通りに振り、
3⁶ = **729通り**すべてで47都道府県を計算し直しました。

| 振った仮定 | 3通り |
|---|---|
| `bh` 度日の基準温度（暖房） | 16.0 / 18.0 / 20.0 ℃ |
| `bc` 度日の基準温度（冷房） | 23.0 / 24.0 / 26.0 ℃ |
| `hloss` 熱損失係数（断熱と家の大きさ） | 200.0 / 234.6 / 270.0 W/K |
| `cop_shift` 暖房COPの水準（機種差） | 0.85 / 1.0 / 1.15 倍 |
| `cool_a` 冷房COPの水準 | 4.3 / 5.0 / 5.7 |
| `defrost_f` 霜取りによる低下 | 0.78 / 0.85 / 0.95 倍 |

### 前提を振っても変わらなかったこと（＝動画で言い切っていること）

| 結論 | 729通り中の生存率 |
|---|---|
| 最も高いのは北海道（札幌） | **100%** |
| 上位5は北海道と東北 | **100%** |
| 東京は中位（729通りすべてで23〜25位） | **100%** |
| 最高と最安の差は4倍以上 | **99%** |
| 効率一定の試算は札幌を2〜3割安く見せる | 中央25.7% / 25〜75%帯 21.3〜28.6% / 全範囲 18.7〜31.6% |

### 前提しだいで入れ替わること（＝動画で断定していないこと）

| | |
|---|---|
| **いちばん安いのはどこか** | 那覇 48% / 鹿児島 30% / 宮崎 22% |
| 倍率の具体値 | 中央5.68倍 / 25〜75%帯 4.89〜7.84倍 / 全範囲 3.81〜13.08倍 |
| 札幌の金額そのもの | 中央240,175円 / 全範囲 141,596〜396,684円 |

だから動画では「最安は◯◯」と言いません。
**「南九州と沖縄は互角」**までが、このデータで言える限界です。

---

## 限界（動画でも同じことを述べています）

1. **月平均気温から計算しています。** 平均が10℃の月でも、暖房は朝の3℃のときに動きます。
   この方法では山と谷がならされるので、示した数字は実際よりやや低めのはずです
2. **基本料金と燃料費調整額を含んでいません。** 燃料費調整額は毎月・会社別に変動するためです
3. **断熱性能を全国で同じにしています。** 実際には寒い地域ほど断熱の高い家が多いので、
   現実の北海道の暖房費はこの計算より低いはずです。
   ここで出したのは、あくまで「同じ家を置いたら」という仮定の話です
4. **COP係数は代表値です。** 実際の効率は機種で違います。だから `cop_shift` で±15%振っています
5. 電力会社の区域は標準的な供給区域で割り当てています（長野県・静岡県は中部電力として扱いました）
