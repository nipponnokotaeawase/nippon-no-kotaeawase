# 日本の答え合わせ — データと計算コード

## なぜ公開しているか

このチャンネルは「なんとなく言われていること」を、公開データだけで計算し直す番組です。視聴者が同じ計算をやり直せるよう、各回について次の3つを置きます。

1. **入力データ** — どこから取ったか（出典URL付き）
2. **計算コード** — Python 3 だけで動く、追加ライブラリ不要の1ファイル
3. **感度分析** — 前提を振ったとき、結論が生き残るかどうかの全結果

どんな試算にも前提があり、前提を変えれば数字は動きます。「前提を振っても変わらなかったこと」と「前提次第で入れ替わること」を分け、変わらなかったことだけを結論として言うようにしています。

## 使ってよいか

- **データとコードは自由に使ってください。** 転載・引用・改変とも、許可は不要です
- 出典を書いていただけると助かります（例: 「日本の答え合わせ v01 の計算より」）
- 元になった気象庁・各電力会社の公開データについては、各提供元の条件に従ってください

## 責任について

計算は公開データと明示した前提にもとづく**試算**です。実際の請求額は、住まいの断熱・使い方・契約プラン・燃料費調整額などで大きく変わります。各回のフォルダにある README の「限界」の項目を必ずお読みください。この試算にもとづく判断の結果について、当方は責任を負いかねます。
